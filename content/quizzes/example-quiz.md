# Web Fundamentals

## semantic-html

### Question

Which HTML element represents the primary content of a document?

### Options

- [ ] A. `<main>`
- [ ] B. `<header>`
- [ ] C. `<aside>`
- [ ] D. `<footer>`

### Answer

A

### Explanation

`<main>` identifies the dominant content of the page. A document should normally contain only one visible `<main>` element.

## css-layout

### Question

Which CSS declaration creates a grid formatting context?

### Options

- [ ] A. `position: grid`
- [ ] B. `display: grid`
- [ ] C. `layout: grid`
- [ ] D. `grid: auto`

### Answer

B

### Explanation

`display: grid` makes an element a grid container, allowing its direct children to be positioned with CSS Grid.

## strict-equality

### Question

In JavaScript, what does the `===` operator compare?

### Options

- [ ] A. Value only
- [ ] B. Type only
- [ ] C. Value and type without coercion
- [ ] D. Object properties recursively

### Answer

C

### Explanation

Strict equality compares operands without type coercion. Values with different types, such as `1` and `"1"`, are not strictly equal.

## http-not-found

### Question

Which HTTP status code means that a requested resource was not found?

### Options

- [ ] A. `200`
- [ ] B. `301`
- [ ] C. `404`
- [ ] D. `500`

### Answer

C

### Explanation

`404 Not Found` indicates that the server cannot find the requested resource. It does not necessarily mean the resource was permanently removed.

## image-alternative

### Question

Which attribute provides a text alternative for an informative HTML image?

### Options

- [ ] A. `title`
- [ ] B. `caption`
- [ ] C. `aria-label`
- [ ] D. `alt`

### Answer

D

### Explanation

The `alt` attribute supplies the image's text alternative. Assistive technologies can use it when the image cannot be perceived.

## responsive-viewport

### Question

Which concept lets a layout adapt to different screen sizes?

### Options

- [ ] A. Responsive design
- [ ] B. Source maps
- [ ] C. Tree shaking
- [ ] D. Server rendering

### Answer

A

### Explanation

Responsive design combines flexible layouts, media queries, and adaptable media so an interface works across viewport sizes.
