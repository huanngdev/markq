# MarkQ documentation

- `SCALING.md` describes the current scalable architecture and extension points.
- `TYPESCRIPT_RULES.md` records the project's TypeScript conventions.
- `archive/legacy-product-plan.md` preserves the original application plan for
  historical context only; it is not the current implementation contract.

Private source material used to author a specific quiz collection does not
belong in this directory. Keep it under `local/quiz-authoring/<project>/`, which
Git ignores by default.
